# Heleket

Криптоплатежи со счётом в валюте магазина (RUB, USD, EUR, USDT или USDC). Монету и сеть выбирает покупатель на странице Heleket. По протоколу это то же самое, что Cryptomus, с другим адресом API.

## Настройки инстанса

Оба значения в кабинете Heleket: «Бизнес», ваш мерчант, «Настройки».

- `PAY_HELEKET_MERCHANT_ID`: Merchant ID, UUID.
- `PAY_HELEKET_API_KEY`: Payment API key из раздела «API-интеграция». Ключ выплат другой, и он не подойдёт.

Расширенные поля по смыслу совпадают с Cryptomus. `PAY_HELEKET_INVOICE_MINUTES`: срок счёта, от 5 до 720 минут, по умолчанию 60. `PAY_HELEKET_ACCEPTED_COINS`: монеты через запятую, можно с сетью (`USDT:tron, TON`), пусто значит все. `PAY_HELEKET_SUBTRACT`: сколько процентов комиссии доплачивает покупатель, 0 по умолчанию. `PAY_HELEKET_ALLOWED_IPS`: проверка адреса отправителя, официальный адрес вебхуков `31.133.220.8`. `PAY_HELEKET_BASE_URL`: пусто означает `https://api.heleket.com`.

## Вебхук

Вставлять его в кабинет не надо, адрес инстанса бот передаёт сам в каждом счёте:

```
<PUBLIC_URL>/webhooks/pay/<instance>/<token>
```

Подпись проверяется всегда. Фильтр по IP включайте, только если бот видит настоящий адрес отправителя без обратного прокси. С Caddy перед ботом оставьте поле пустым.

## Подводные камни

Подпись у Heleket считается от тела в том виде, в каком его печатает PHP: слэши экранируются как `\/`, Unicode остаётся как есть. Бот это учитывает, настраивать ничего не нужно.

Недоплата (`wrong_amount`) не зачисляется, платёж уходит в «Требует внимания», дальше решаете сами. Переплату бот засчитывает по цене счёта. Отменённый по сроку счёт, по которому всё же заплатили, принимается.

Песочницы нет, флаг `PAY_HELEKET_TEST_MODE` только помечает события инстанса тестовыми. Тестовые вебхуки из кабинета на боевом инстансе отклоняются. Возвраты через бота не делаются. Список поддерживаемых фиатных валют в документации Heleket не приведён: рубль и евро проверяйте на деле маленьким платежом.

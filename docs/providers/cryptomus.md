# Cryptomus

Оплата криптовалютой. Счёт выставляется в валюте магазина (179 RUB, например), а монету и сеть покупатель выбирает на странице Cryptomus. Подходят магазины в RUB, USD, EUR, USDT и USDC.

## Настройки инстанса

В личном кабинете откройте «Бизнес», нужный мерчант, «Настройки».

- `PAY_CRYPTOMUS_MERCHANT_ID`: Merchant ID, это UUID.
- `PAY_CRYPTOMUS_API_KEY`: ключ раздела «API-интеграция», именно **Payment API key**. Если его ещё нет, сгенерируйте. Ключ для выплат (Payout) не подойдёт, Cryptomus ответит отказом.

Остальное по желанию, всё в расширенных:

- `PAY_CRYPTOMUS_INVOICE_MINUTES`, срок жизни счёта от 5 до 720 минут, по умолчанию 60;
- `PAY_CRYPTOMUS_ACCEPTED_COINS`, список монет, при желании с сетью: `USDT:tron, TON, BTC`. Пусто значит все монеты мерчанта;
- `PAY_CRYPTOMUS_SUBTRACT`, какую долю комиссии доплачивает покупатель, от 0 до 100 процентов. При 0 комиссию платите вы;
- `PAY_CRYPTOMUS_ALLOWED_IPS`, проверка адреса отправителя (официальный адрес вебхуков `91.227.144.54`).

## Вебхук

В кабинет ничего вставлять не нужно: бот сам кладёт адрес вебхука инстанса в каждый счёт. Он имеет вид

```
<PUBLIC_URL>/webhooks/pay/<instance>/<token>
```

и должен быть от 6 до 255 символов, что для обычного домена выполняется. Подпись проверяется всегда. Поле `ALLOWED_IPS` включайте, только если бот видит настоящий адрес отправителя, то есть без Caddy или другого обратного прокси. За прокси проверка по IP сломает приём вебхуков, а подпись и так защищает.

## Недоплата, переплата, тесты

Недоплата приходит статусом `wrong_amount`. Бот не зачисляет такие платежи: сумма не совпала, платёж попадает в «Требует внимания» и разбирается вручную. Переплата (`paid_over`) засчитывается по цене счёта, лишнее остаётся у вас. Если счёт отменился по сроку, а покупатель всё же заплатил, платёж принимается.

Список поддерживаемых фиатных валют Cryptomus не публикует. Если валюта вашего магазина не подошла, в ошибке будет что-то вроде «The currency was not found».

Песочницы нет. `PAY_CRYPTOMUS_TEST_MODE=true` лишь помечает все события инстанса как тестовые. Тестовые вебхуки из кабинета (`/v1/test-webhook/payment`) боевой инстанс отклоняет, даже если подставить настоящий номер счёта. Возвратов через бота нет, потому что Cryptomus требует для возврата адрес кошелька покупателя.

# Robokassa

Оплата картой и СБП на странице Robokassa, только рубли. Бот собирает подписанную ссылку, к Robokassa за ней не обращается.

## Настройки инстанса

Всё лежит в личном кабинете: «Мои магазины», нужный магазин, «Технические настройки».

- `PAY_ROBOKASSA_MERCHANT_LOGIN`: «Идентификатор магазина», латинское имя.
- `PAY_ROBOKASSA_PASSWORD1`: «Пароль #1». Им подписывается ссылка на оплату.
- `PAY_ROBOKASSA_PASSWORD2`: «Пароль #2». Им Robokassa подписывает уведомление об оплате.
- `PAY_ROBOKASSA_HASH_ALGORITHM`: алгоритм хеша. Он должен совпадать с «Алгоритмом расчёта хеша» в тех же настройках, иначе подписи не сойдутся. По умолчанию `md5`, лучше выставить `sha256` и там, и тут.

`PAY_ROBOKASSA_CULTURE` (язык страницы, `ru` или `en`) и `PAY_ROBOKASSA_BASE_URL` менять незачем.

## Result URL

В тех же «Технических настройках» заполните Result URL, метод POST:

```
<PUBLIC_URL>/webhooks/pay/<instance>/<token>
```

Success URL и Fail URL можно оставить пустыми или вписать ссылку на бота. Бот ждёт от кассы подпись по Паролю #2 и отвечает ровно `OK<номер счёта>`, как требует Robokassa. Уведомление приходит только при успешной оплате.

## Пароли и тесты

Проверка ключей умеет проверить идентификатор магазина, Пароль #2 и алгоритм (через запрос статуса несуществующего счёта). Пароль #1 так не проверить, он вылезет только на первой оплате: если ссылка ведёт на ошибку подписи, смотрите на него и на алгоритм.

Тесты у Robokassa идут по отдельному набору паролей. На время проверки включите `PAY_ROBOKASSA_TEST_MODE=true` и впишите тестовые Пароль #1 и #2 (они в блоке «Параметры проведения тестовых платежей»), алгоритм тот же. Статус тестовых платежей через API не виден, поэтому в тестовом режиме бот полагается только на уведомление. После проверки верните боевые пароли и выключите режим.

Адреса Robokassa бот не проверяет, подписи достаточно. Чеки по 54-ФЗ он не передаёт: фискализацию настраивайте средствами самой Robokassa. Возвраты тоже делаются в кабинете. Robokassa о них не уведомляет, а оплаченные счета бот больше не опрашивает, так что в боте возврат не отразится.

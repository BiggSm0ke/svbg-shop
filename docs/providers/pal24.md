# Pal24 (PayPalych)

Карты и СБП на странице Pal24, она же PayPalych и Pally. Валюты рубль, доллар и евро, по умолчанию рубль.

## Настройки инстанса

Всё в кабинете Pal24 (pal24.pro или pally.info).

- `PAY_PAL24_API_TOKEN`: токен со страницы «API интеграции», выглядит как `число|строка`. Им подписываются запросы, и он же участвует в подписи уведомлений. Токен один на мерчанта, не на магазин.
- `PAY_PAL24_SHOP_ID`: ID магазина из раздела «Магазины», что-то вроде `LXZv3R7Q8B`. Без него не работают Result, Success и Fail URL.
- `PAY_PAL24_PAYMENT_METHOD`: `any` (покупатель выбирает сам, по умолчанию), `BANK_CARD` или `SBP`.
- `PAY_PAL24_PAYER_PAYS_COMMISSION`: если включить, Pal24 добавит свою комиссию к сумме для покупателя. На баланс в любом случае зачисляется сумма счёта.
- `PAY_PAL24_BILL_TTL`: срок жизни счёта в секундах, 0 значит «не передавать» и тогда действует срок самой Pal24.
- `PAY_PAL24_BASE_URL`: по умолчанию `https://pal24.pro`. `https://pally.info` отвечает так же, можно переключиться, если один из адресов недоступен.

## Postback

В запросе создания счёта адреса уведомлений нет, их задают в настройках магазина. В поле Result URL (это postback об оплате) вставьте

```
<PUBLIC_URL>/webhooks/pay/<instance>/<token>
```

Если хотите, чтобы бот узнавал о возвратах и чарджбэках, тот же адрес вставьте и в Refund URL с Chargeback URL. Success и Fail URL бот не передаёт, их можно не трогать. По документации домен в них должен совпадать с доменом магазина, поэтому ссылку на t.me туда лучше не ставить.

## Слабая подпись

Подпись postback закрывает только сумму и номер заказа. Статус в ней не участвует: у `SUCCESS` и `FAIL` для одной суммы и одного заказа подпись совпадает. Поэтому бот не принимает postback на веру, а перечитывает счёт через `bill/status` и решает по ответу API. Для вас это значит, что после каждого уведомления будет лишний запрос.

`UNDERPAID` (заплатили меньше) бот не зачисляет, платёж уходит в «Требует внимания». `OVERPAID` зачисляется по сумме счёта.

Минимальная и максимальная суммы в документации не названы. Недопустимая сумма вернёт ошибку `invalid_amount`. Если запросы получают `ip_access_denied`, у вашего аккаунта включён белый список IP: попросите поддержку добавить адрес сервера бота.

Тестового режима нет, проверка идёт реальным платежом на небольшую сумму. Возвраты через API Pal24 доступны только по запросу в поддержку, поэтому бот их не делает.

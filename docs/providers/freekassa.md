# Freekassa

Платёжная форма Freekassa: карта, СБП и крипта, покупатель выбирает способ сам. Принимает рубли, доллары, евро, гривны и тенге.

## Настройки инстанса

Всё из кабинета Freekassa, раздел «Настройки» магазина.

| Поле | Что это |
|---|---|
| `PAY_FREEKASSA_SHOP_ID` | ID магазина, цифры |
| `PAY_FREEKASSA_SECRET_WORD` | «Секретное слово»: им подписывается ссылка на форму оплаты |
| `PAY_FREEKASSA_SECRET_WORD_2` | «Секретное слово 2»: им Freekassa подписывает уведомления |
| `PAY_FREEKASSA_API_KEY` | «API ключ». Нужен всегда, потому что бот перепроверяет оплату через API |

Слова 1 и 2 легко перепутать: если подпись уведомления не сходится, смотрите сначала сюда.

По умолчанию бот открывает покупателю обычную форму (`PAY_FREEKASSA_CHECKOUT_MODE=form`), и без запросов к API ссылка собирается сама. Предложить конкретный способ можно через `PAY_FREEKASSA_PAYMENT_SYSTEM`, это параметр `i` формы. Покупатель всё равно сможет его сменить. Номера способов смотрите в документации Freekassa или в запросе `/currencies`: например 42 это СБП, 12 это МИР, 15 это USDT TRC20.

Режим `api` создаёт заказ запросом на стороне Freekassa и без `PAYMENT_SYSTEM` не работает. Ещё он требует email и IP плательщика, а бот их не знает, поэтому впишите свою почту в `PAY_FREEKASSA_PAYER_EMAIL` и внешний IP сервера в `PAY_FREEKASSA_PAYER_IP`. Если режим `form` вас устраивает, ничего из этого не нужно.

## Вебхук

В настройках магазина укажите «URL оповещения», а «Метод оповещения» поставьте POST (бот принимает только его):

```
<PUBLIC_URL>/webhooks/pay/<instance>/<token>
```

Включите и подтверждение платежа: Freekassa повторяет уведомление, пока не получит ответ `YES`, и бот отвечает именно так. Приходят уведомления только об успешной оплате.

## Подпись, IP и тесты

Подпись уведомления это MD5, а валюты в нём нет. Поэтому при `PAY_FREEKASSA_CONFIRM_VIA_API=true` (по умолчанию) уведомление только запускает проверку заказа через API, а деньги зачисляются по её ответу. Если выключить, деньги зачисляются прямо по подписанному уведомлению, а валюта берётся из эха, которое бот сам кладёт в ссылку. Рекомендуется оставить по умолчанию.

Бот принимает уведомления только с адресов Freekassa (`PAY_FREEKASSA_ALLOWED_IPS`). За обычным Caddy это работает само. Если перед ботом стоит Cloudflare, настоящего адреса отправителя бот не видит, и проверку надо выключить значением `off`.

Минимальные суммы для разных способов указаны в `/currencies`, бот их не проверяет. Тестового режима, который помечал бы уведомления, у Freekassa нет. Для проверки заведите отдельный магазин и на время впишите его ID, слова и API-ключ вместо боевых.

# Это платежи

СБП и карты на платёжной странице «Это платежи» (Payment Page), рубли. Бот не обращается к кассе при создании платежа: он сам собирает подписанную ссылку, и платёж появляется у провайдера только после того, как покупатель подтвердит форму.

## Настройки инстанса

Доступ выдаёт поддержка «Это платежи» (info@etoplatezhi.ru) при подключении: тестовый и рабочий проекты заводятся отдельно.

- `PAY_ETOPLATEZHI_PROJECT_ID`: числовой ID проекта. Он же виден в Dashboard, в разделе «Проекты».
- `PAY_ETOPLATEZHI_SECRET_KEY`: секретный ключ проекта. Им подписываются ссылки, запросы к Gate и оповещения (HMAC-SHA512). У тестового проекта свой ключ.
- `PAY_ETOPLATEZHI_LIFETIME_MIN` (расширенное): сколько минут форма принимает оплату, по умолчанию 60, до 43000.
- `PAY_ETOPLATEZHI_LANGUAGE`: язык формы, `ru` или `en`.
- `PAY_ETOPLATEZHI_RETURN_URL`: куда ведёт кнопка возврата, пусто значит ссылка на бота.
- `PAY_ETOPLATEZHI_PAYMENT_PAGE_URL` и `PAY_ETOPLATEZHI_API_URL`: адреса формы и Gate API, менять только по указанию поддержки.

## Оповещения

Бот кладёт адрес оповещений в ссылку (`merchant_callback_url`), вставлять его в Dashboard не нужно:

```
<PUBLIC_URL>/webhooks/pay/<instance>/<token>
```

Подписан весь JSON оповещения, поле `signature` лежит в корне. ID проекта в оповещении должен совпадать с тем, что указан в настройках бота, иначе оповещение отклоняется.

## Ограничения и подвохи

Состав и даже имена параметров оповещения настраиваются на уровне проекта. Бот рассчитан на базовый формат из документации. Если поддержка что-то переименовала, оповещения перестанут разбираться, поэтому попросите оставить базовый формат.

Запрос статуса идёт на Gate API, и доступ к нему может быть ограничен белым списком IP. Ответ 403 означает, что адрес сервера бота надо добавить в список (через поддержку). Адреса, с которых приходят оповещения, публично не названы, так что их бот не проверяет, подпись достаточна.

Лимиты сумм публично не опубликованы, по схеме Gate минимальный платёж 1 копейка, реальные зависят от проекта. Чарджбэки в оповещениях не приходят, они видны только в Dashboard. Возвраты тоже делаются в Dashboard.

Признака теста в оповещении нет. Тестовый проект отличается только ID и ключом. На время проверки впишите их вместо боевых и включите `PAY_ETOPLATEZHI_TEST_MODE=true`, потом верните боевые и выключите режим.

# RollyPay

Оплата по СБП на странице RollyPay, только рубли. Бот создаёт платёж, отправляет покупателя по ссылке и ждёт вебхук.

## Настройки инстанса

В кабинете RollyPay, в разделе API вашей кассы, нужны два секрета. Не путайте их.

- `PAY_ROLLYPAY_API_KEY` («API-ключ»). Бот шлёт его в заголовке `X-API-Key` с каждым запросом.
- `PAY_ROLLYPAY_SIGNING_SECRET` («Секрет подписи вебхуков»). Он лежит там же, в блоке вебхуков. Им RollyPay подписывает уведомления, и на запросы он не влияет.

Остальные два поля трогать обычно не надо. `PAY_ROLLYPAY_PAYMENT_METHOD` фиксирует способ на стороне кассы (например `sbp`); если оставить пустым, способ выберет покупатель на странице RollyPay. `PAY_ROLLYPAY_BASE_URL` по умолчанию `https://api.rollypay.io/api/v1`.

Проверка ключей ничего не создаёт: бот спрашивает у кассы статус несуществующего платежа. Ответ 401 или 403 значит, что ключ не принят. Если вместо JSON пришла HTML-страница, по этому адресу отвечает не RollyPay, проверьте `BASE_URL`.

## Вебхук

В кабинете RollyPay вебхук задаётся один раз на магазин, не на счёт. Вставьте туда адрес инстанса. Бот показывает его в настройках, «Платёжки», раздел RollyPay, как только касса включена:

```
<PUBLIC_URL>/webhooks/pay/<instance>/<token>
```

Касса подписывает тело вместе с меткой времени (`X-Timestamp`). Бот отвечает `200`, а на любой другой код касса повторяет запрос с растущей паузой.

## Что проверить, если не работает

Бот отбрасывает вебхуки, у которых метка времени отличается от его часов больше чем на 5 минут (ответ 401). Если таких набирается больше пяти за час, в «Требует внимания» появится предупреждение про расхождение часов. Обычно виноват сервер без синхронизации времени: поставьте NTP.

Минимум платежа 179 ₽, меньшую сумму бот кассе не отправит. Это значение, как и адрес API, взято из рабочей конфигурации, а не из официальной документации, поэтому сверьте оба с тем, что написано в вашем кабинете.

Если платёж истёк, а покупатель всё же заплатил, деньги зачтутся: поздний `paid` после `expired` бот принимает. Возвраты и чарджбэки он только фиксирует (платёж помечается возвращённым, приходит уведомление админам). Через API кассы бот ничего не возвращает.

Тестовый режим (`PAY_ROLLYPAY_TEST_MODE=true`) добавляет в запрос флаг `test`. Тестовое событие на боевом инстансе бот отклоняет с кодом 400.
